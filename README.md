# Site MMLB 2026

Site personnel de Matthieu Moreau-Le Breton : profil et CV, entrepreneuriat (Convergence), recherche (projet de thèse 2027), éducation et outils.

Site statique sans dépendance : ouvrir `index.html` dans un navigateur.
Les sources de l’aperçu sont dans `src/body.html` ; `index.html` est la version complète à héberger.
Les passages encore à rédiger sont marqués « À compléter » (classe CSS `todo`).

Hébergement possible avec GitHub Pages : Settings → Pages → Deploy from a branch → `main` / racine.
